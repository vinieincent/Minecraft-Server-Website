          So kommst du auf den Server

          1. Anmelden Klick auf „Anmelden“, Minecraft-Namen eintragen und absenden. Das dauert eine Minute und kostet nichts.
          2. IP einfügen In Minecraft Mehrspieler, dann Server hinzufügen, und die kopierte IP bei „Serveradresse“ einfügen.
          3. Spielen Der Server öffnet am 6. November um 18 Uhr. Ab dann kannst du beitreten.
